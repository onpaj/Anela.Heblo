## Why it matters
Business-level validation errors (handler returns `RequiredFieldMissing`) are silently swallowed, and the client receives `200 OK` regardless. This breaks the contract between the handler's error reporting and the HTTP layer. It also means that if either handler gains additional error paths in the future (e.g., `TileNotFound`, `Unauthorized`), they will be silently ignored until this is noticed and fixed. The inconsistency with every other controller is a maintenance hazard.

## Suggested fix

{

    var response = await _mediator.Send(request);
    return HandleResponse(response);
}

[HttpPost("tiles/{tileId}/disable")]
public async Task<ActionResult> DisableTile(string tileId)
