## Why it matters
The string-based approach has two real costs:
1. **Removed compile-time safety**: invalid values are only caught at runtime (after the request reaches the handler).
2. **Duplicated validation state**: the valid values are encoded in three separate places — the `HashSet`, the switch arms, and the controller default. Adding a fourth grouping mode requires touching all three locations.

This is a KISS violation: the three valid modes are a closed, finite set perfectly suited to an enum.
