## Finding
`MarketingInvoiceImportService.ImportAsync()` calls `_repository.ExistsAsync(platform, transactionId)` inside a `foreach` loop over every transaction returned by the source adapter. Each call is a separate `AnyAsync` round-trip to the database.

File: `backend/src/Anela.Heblo.Application/Features/MarketingInvoices/Services/MarketingInvoiceImportService.cs`, lines 49–66 (the `ExistsAsync` branch inside the `foreach`).

Repository interface: `backend/src/Anela.Heblo.Domain/Features/MarketingInvoices/IImportedMarketingTransactionRepository.cs`.

For a batch of N transactions from the Meta Ads or Google Ads adapter, this produces N separate SQL `SELECT EXISTS(...)` queries, one per transaction.

## Why it matters
This violates the KISS principle: the batch case (even a modest 50–200 transactions) incurs 50–200 round trips when a single `WHERE TransactionId IN (...)` query would answer the same question. As billing history grows or if lookback windows are extended, this compounds linearly. It also makes the import loop harder to reason about, because the duplicate-detection logic is split between the in-memory `stagedIds` set (already present for within-run deduplication) and the per-row DB check.

## Suggested fix
1. Add a single bulk-lookup method to the repository interface:
   ```csharp
   // IImportedMarketingTransactionRepository
   Task<HashSet<string>> GetExistingTransactionIdsAsync(
       string platform, IEnumerable<string> transactionIds, CancellationToken ct);
   ```
2. In `MarketingInvoiceImportService.ImportAsync`, before the loop, call it once:
   ```csharp
   var allIds = transactions.Select(t => t.TransactionId).ToList();
   var alreadyImported = await _repository.GetExistingTransactionIdsAsync(source.Platform, allIds, ct);
   ```
3. Replace the per-row `ExistsAsync` call with `alreadyImported.Contains(transaction.TransactionId)`.

The `stagedIds` set can then be removed — it becomes redundant because the in-memory `alreadyImported` set already covers within-run deduplication (since the batch is fetched before the loop starts).
