## Why it matters
Any correction to the formula (e.g. fixing an edge-case where `TotalCount` is exactly divisible by `PageSize`) must be applied in two places. The handlers are siblings in the same module — divergence would be a silent bug that only surfaces on one code path. This violates DRY at the application layer and makes future fixes error-prone.

## Suggested fix
Extract the calculation to a private static helper in the Journal module, e.g. a small method in a shared file or inline in one of the handlers as a local function:

\`\`\`csharp
private static (int TotalPages, bool HasNextPage, bool HasPreviousPage) CalcPagination(
    int totalCount, int pageNumber, int pageSize)
{
    var totalPages = (int)Math.Ceiling((double)totalCount / pageSize);
    return (totalPages,
            HasNextPage: pageNumber * pageSize < totalCount,
            HasPreviousPage: pageNumber > 1);
}
\`\`\`

Both handlers call the helper and spread the result into their response objects. No cross-module abstraction needed — keep it local to the Journal feature folder.
