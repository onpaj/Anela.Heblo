`GiftPackageManufactureService.GetGiftPackageDetailAsync` in `backend/src/Anela.Heblo.Application/Features/Logistics/UseCases/GiftPackageManufacture/Services/GiftPackageManufactureService.cs:111-118` fetches ingredient catalog data one item at a time inside a `foreach` loop:

```csharp
var ingredientCodes = productParts.Select(p => p.ProductCode).Distinct().ToList();
var ingredientCatalog = new Dictionary<string, LogisticsCatalogItem>(StringComparer.Ordinal);
foreach (var code in ingredientCodes)
{
    var item = await _catalogSource.GetCatalogItemAsync(code, cancellationToken);
    if (item != null)
        ingredientCatalog[code] = item;
}
```

`ILogisticsCatalogSource` only exposes `GetCatalogItemAsync(string code, ...)` — there is no batch variant. For a gift package with N ingredients, this is N sequential round-trips to the underlying catalog source.

This method is called from two paths: `GetGiftPackageDetailAsync` (direct read), and — importantly — `CreateManufactureAsync` (line 165), which means every manufacture operation also pays this N+1 cost before creating stock operations.

## Why it matters
If the catalog source implementation performs network I/O (Shoptet API, database) each call, N+1 queries add latency proportional to the number of ingredients. For a gift package with 5 ingredients, manufacture and detail views make 5 sequential catalog calls where 1 batch call would suffice. This also makes performance testing harder: a slow catalog source in production is not visible from the interface contract alone.

## Suggested fix
Add a batch method to `ILogisticsCatalogSource`:

```csharp
Task<IReadOnlyDictionary<string, LogisticsCatalogItem>> GetCatalogItemsAsync(
    IReadOnlyList<string> codes, CancellationToken cancellationToken);
```

Implement it in the adapter (batch DB query or a parallel fan-out to the external API, depending on the source). Replace the loop in `GetGiftPackageDetailAsync` with a single call. The existing single-item method can be kept for callers that genuinely need it one at a time.
