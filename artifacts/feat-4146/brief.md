Frontend code consuming `CreateJournalEntryRequest` / `UpdateJournalEntryRequest` gets no compile-time hint that `title` is mandatory. The validation gap only surfaces at runtime as a domain error, not a type error — a category of bug the code-generation pipeline is specifically meant to prevent.
