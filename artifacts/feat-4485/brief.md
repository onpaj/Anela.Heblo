## Why it matters
Both application-layer handlers must know an implementation detail of a domain method. If the sentinel ever changes, both call sites silently break. This violates the domain-layer contract (callers should not inspect internal sentinel values) and duplicates the same logic at two sites. It is a Dependency Inversion smell: the application layer depends on a hidden detail of the domain.

Change `CalculateForecastedDays` to return `decimal?` (null when there is no consumption history) instead of `decimal.MaxValue`. Both call sites become:
```csharp

```
