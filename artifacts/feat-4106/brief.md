## Finding
`LeafletGenerateTab.tsx` (lines 27–51) calls the API inline by directly instantiating the NSwag-generated client and awaiting `client.leaflet_Generate(...)`, while every other Leaflet API call goes through a dedicated React Query hook in `frontend/src/api/hooks/useLeaflet.ts`:

| Upload document | `useUploadLeafletDocumentMutation` hook |
| Submit feedback | `useSubmitLeafletFeedbackMutation` hook |
| **Generate leaflet** | ❌ Inline `getAuthenticatedApiClient().leaflet_Generate()` in component body |

The `useLeaflet.ts` file has no `useGenerateLeafletMutation` hook.

## Why it matters
Two competing API call patterns within the same module makes the codebase harder to maintain. The generate call also cannot benefit from React Query's mutation lifecycle helpers (cache invalidation, optimistic updates, retry control, loading/error state via `useMutation`) and is harder to test in isolation.

## Suggested fix
Add a `useGenerateLeafletMutation` hook to `frontend/src/api/hooks/useLeaflet.ts` that wraps the generate call with `useMutation`. Refactor `LeafletGenerateTab.tsx` to use this hook, replacing the inline `getAuthenticatedApiClient` call and the manual `isLoading` / error state management.
